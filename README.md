# Game Portal Capstone
This repo is for my team's senior-design project. It is a gaming portal web
application that allows users to search for, filter, and play games. Users can
register an account and create a profile in order to submit requests to upload
new games. There is an admin dashboard where an administrator can easily 
approve or deny game upload requests. Game and user data is stored in a 
relational database.

# Stack and Tools
- Vue.js frontend
- Spring Boot backend
- PostgreSQL database + JPA
- Scrum for project management
- Git for version control

# What I Worked On
- Search/filter functionality
- Creating quiz to match users to an appropriate game
- Employing a featured game of the day
- Defining REST API contracts
- User authentication
- User and admin profiles
- Game upload requests and management

# Current Status
- Frontend is in place.
- Backend infrastructure is in place.
- Currently working on database and wiring.

# Walkthrough
1. User enters URL to game portal.
2. Home page displays all games. User can search by keyword or filter by 
   different criteria.
3. User can select game to view its details and play in the browser.
4. User can register an account and create a profile.
5. User can submit a game upload request.
6. An administrator can login and approve or deny game upload requests.
